### 🧭 Sobre mim

Sou formado em Desenvolvimento de Sistemas pelo **Senac** e atualmente estou cursando **Análise e Desenvolvimento de Sistemas** na faculdade — encarando essa segunda etapa como um aprofundamento, não como um recomeço.

Comecei no Front-end e Web Design, e venho expandindo minha atuação para Back-end e banco de dados a cada novo projeto. Não me interessa colecionar tecnologias no README só pra impressionar: cada uma das que aparecem abaixo eu usei pra resolver um problema real.

- 🎓 Técnico em Desenvolvimento de Sistemas (Senac) + graduação em andamento
- 🔨 Foco atual: sair do Front-end puro e consolidar uma atuação Full-stack
- 🧩 Projeto em desenvolvimento: **Foodie**, um app de delivery com Next.js 15 + TypeScript, API própria e mais de 240 produtos catalogados
- 🤝 Prioridade em código legível e em trabalho de equipe, não só em "fazer funcionar"
