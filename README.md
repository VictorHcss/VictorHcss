### 🧭 Sobre mim

Sou formado em **Desenvolvimento de Sistemas** pelo Senac e atualmente curso **Análise e Desenvolvimento de Sistemas** na faculdade — encaro essa etapa como aprofundamento, não como recomeço.

Comecei no Front-end e Web Design, e venho ampliando minha atuação para Back-end e banco de dados a cada novo projeto. Não coloco tecnologia aqui só pra parecer completo: cada uma abaixo eu já usei pra resolver um problema de verdade.

- 🎓 Técnico em Desenvolvimento de Sistemas (Senac) + graduação em ADS em andamento
- 🔨 Foco atual: consolidar uma atuação Full-stack, saindo do Front-end puro
- 🧩 Projeto em desenvolvimento: **Foodie** — app de delivery em Next.js 15 + TypeScript, com API própria, banco de dados estruturado e mais de 240 produtos catalogados
- 🤝 Prioridade em código legível, boas práticas e trabalho em equipe
